# 长生车机 · Tesla 风格极简桌面 v5（诺威达 K4001 / Android 8.1 专版）

专为 **诺威达 K4001（`sp9853i_1h10_vmm`，Android 8.1 / x86，纯离线使用）** 打造的极轻量原生桌面。

## 为什么这套 APK 在老车机上特别流畅？
- **零 WebView 吃内存**：左侧 3D 立体车模、柔和渐变大灯、高亮刹车尾灯、「长生车机」车牌、暗色路面与树城动画全部用 **Android 原生硬件加速绘图** 编写，安装包仅约 **3–5 MB**，常驻内存极低；静止或切进高德/ZLINK 时自动暂停动画（0% GPU 占用）。
- **断电自动结算停车计时**：点击右上角「停车计时」立即同步写入本地存储与离线 GPS 坐标，边框切换为**顺时针跑动橙色渐变**；即使车机彻底断电，下次启动或起步（车速 > 5 km/h）会自动算出本次总停车时长并存入历史记录。

## 只有 iPhone 手机，怎么打包并装上车机？
### 第 1 步：用 iPhone Safari 云端打包出 `.apk`
1. 在 GitHub 网页版新建一个仓库，把本压缩包解压后的文件上传进去。
2. 点开仓库顶部的 **Actions**，等 `Build Changsheng Car Launcher v5 APK` 变绿（约 2 分钟）。
3. 点进去在页面最底部 **Artifacts** 下载 `ChangshengCarLauncher-v5-APK`，在 iPhone「文件」里点一下解压得到 `app-debug.apk`。

### 第 2 步：把 `app-debug.apk` 传进车机（二选一）
- **方法 A（有 U 盘 + iPhone 转接头）**：把 `app-debug.apk` 拷进 U 盘插车机，打开车机「文件浏览器」点击安装。
- **方法 B（没有转接头，零配件）**：车机临时连一下 iPhone 个人热点，在车机自带「浏览器」里登录你的 GitHub / 网盘直接下载并安装 `app-debug.apk`，装完即可断开热点离线使用。

### 第 3 步：设为默认桌面、防止自动退出
1. 先卸载之前装的「嘟嘟桌面PRO」（避免两个第三方桌面冲突）。
2. 进入车机 **「设置 → 应用和通知 → 默认应用 → 主屏幕应用」**，选择 **「长生车机」**。
3. 首次打开会请求定位权限（用于 GPS 车速与停车地点记录），点「允许」即可。
4. 激活奇瑞艾瑞泽原车协议：打开原车机 **「系统设置 → 工厂设置」**，诺威达 K4001 常见密码 **`1617`**（或 `16176699` / `8888`），选择对应协议盒品牌 + 奇瑞艾瑞泽重启即可。
